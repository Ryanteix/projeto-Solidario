# Pasta de imagens

O site atualmente utiliza URLs remotas do Unsplash para carregar as imagens de demonstração. Para entregar assets locais, baixe imagens apropriadas com licença compatível, otimize-as (por exemplo, WebP e AVIF) e salve-as nesta pasta. Depois, substitua as URLs `https://images.unsplash.com/...` nos arquivos HTML por caminhos relativos, como `img/voluntarios.webp`.

Não use imagens de pessoas atendidas por organizações sem autorização adequada.
